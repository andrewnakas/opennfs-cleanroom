OPEN ROAD

A browser build of an open-source classic racing engine, running on a track, cars, textures and sound that were all made for this project. Back to the game

What "clean room" means here

The engine can read the track and car file formats of several classic PC racing games. This build contains no data from any commercial game: the circuit is generated from a formula, the cars are original shapes with invented names, the textures are procedural, and every sound is synthesised in your browser. The files are written in the formats the engine understands by a generator that was written from the open-source parser only.

None of the artwork bundled with the upstream engine repository is used either; it is regenerated too.

Content made for this project (CC0 1.0)

  • Track "Cedar Ridge": geometry, collision, driving line, scenery placement
  • Cars "Clean Coupe", "Clean Hatch" and "Clean Wedge" by the fictional "Cleanroom Motors". They are not based on any real vehicle.
  • All textures, sky, sprites, menu images
  • All sound effects and music (generated live with WebAudio)
